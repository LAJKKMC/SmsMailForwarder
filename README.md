# 短信邮件转发

这是一个 Android Studio 项目。应用收到短信广播后，可按发件号码筛选，并通过 SMTP 将号码、时间和短信正文发到固定邮箱。只申请接收短信和联网权限，不请求通讯录、短信读取历史或短信发送权限。

## 构建

使用 Android Studio 打开本目录，安装 Android SDK 35 与 JDK 17，然后执行 Gradle Sync，再从 Build > Build APK(s) 生成 APK。首次安装时授予“短信”权限。

## 配置

1. 在 Pura 70 上安装 APK 并打开。
2. 填入验证码发送方号码（建议填写；留空将转发所有短信）、收件邮箱、SMTP 主机/端口、邮箱登录名和应用专用密码。
3. 点击“保存并启用”，再点击“发送测试邮件”。
4. 在系统设置中允许应用自启动、后台运行和联网；关闭针对该应用的电池优化/应用启动限制。设置名称会因 HarmonyOS/EMUI 版本而异。

## 邮箱

Gmail 示例：`smtp.gmail.com`，端口 `465`（SSL）或 `587`（STARTTLS）；使用 Google 账号的应用专用密码。其他邮箱请使用服务商提供的 SMTP 地址和授权码/应用密码。不要把邮箱主密码交给不可信应用。

## 重要限制

- Android 系统允许有 `RECEIVE_SMS` 权限的应用监听新短信广播；实际能否在 Pura 70 的特定系统版本、地区固件和权限策略中工作，需在目标手机上安装测试。
- 手机必须开机、SIM 卡能收短信且有互联网。省电策略可能延迟或停止邮件发送。
- 短信正文会经 SMTP 传输并保存在收件箱；验证码邮件本身也有账号安全风险。
- 此版本没有离线队列/失败重试。若设备离线或 SMTP 暂时失败，邮件不会自动补发。应先测试稳定性。
- SMTP 密码保存在应用私有偏好设置中，未做硬件密钥库加密；建议使用可随时撤销的专用密码。
